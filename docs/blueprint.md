# **App Name**: MatchaMe

## Core Features:

- Map Display: Display a map centered on Malaysia with markers indicating matcha cafe locations.
- Cafe Filtering: Allow users to filter cafes based on user ratings.
- Cafe Details: Provide essential details for each cafe, including address, opening hours, menu links, and user ratings.
- AI Matcha Concierge: AI tool will be trained to respond to queries about 'hidden gems' or 'unique menu items' at nearby locations.

## Style Guidelines:

- Primary color: Deep matcha green (#43A047) to reflect the essence of matcha.
- Background color: Off-white (#F5F5DC), providing a clean and calming backdrop.
- Accent color: Muted gold (#B8860B) to highlight key interactive elements and add a touch of elegance.
- Prioritize a clean and modern sans-serif font for optimal readability.
- Use minimalist icons to represent different functionalities within the app.
- Employ a grid-based layout for a structured and visually appealing design.
